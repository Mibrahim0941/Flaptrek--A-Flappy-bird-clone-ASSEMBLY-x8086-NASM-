# Flaptrek--A-Flappy-bird-clone-ASSEMBLY-x8088-NASM-
A flappy bird clone in iapx8088 NASM assembly
Provides a graphical Interface in 320*200 graphics mode.
Advance low level programming.
Handles Multitasking by playing both music and running game simultaneously.
Handled important interrupt handling(proper hooking and unhooking of keyboard and other services).
Environment Used : DOSBOX emulator to run
